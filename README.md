# Math-Quest



\- Five levels of challenges.

\- Addition, subtraction, multiplication, and division.

\- Random question generation.

\- Score tracking and instant feedback.

\- Victory screen with particle effects.



\## Concepts Implemented



\*\*OOP Principles\*\*

\- Encapsulation

\- Inheritance

\- Polymorphism

\- Abstraction



\*\*Design Patterns\*\*

\- Factory Pattern

\- Observer Pattern

\- State Pattern



\*\*Algorithms\*\*

\- Difficulty-based question generation

\- Linear Search (O(n) worst-case time complexity)



\## How to Run

1\. Clone the repositorY

2\. Open Unity Hub.

3\. Add the cloned project.

5\. Open `FrontScene` and press Play.
